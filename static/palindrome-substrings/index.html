先定规则

什么算“回文子串”？

子串必须是原字符串里连续的一段。比如 ababa 里的 aba 是子串，aaa 不是，因为中间跳过了 b。回文就是从左读和从右读一样。

所以这类题常见问题只有几种：判断一段是不是回文、数一共有多少段、找最长的一段、把整串切成若干回文段，或者在多个回文段之间做选择。

  1. 1先会看指针两头字符相等，才有继续往外扩的资格。
  2. 2再会数答案每成功扩一层，就新增一个回文子串。
  3. 3最后换模型计数用中心扩展，分割和最短切分再上 DP。

LC 647. Palindromic Substrings

题目要求：给一个字符串 s，返回它里面有多少个回文子串。官方难度 Medium，约束是 1 <= s.length <= 1000，字符都是小写英文字母。

LeetCode 官方出处

1. 题目到底在问什么

不要先想复杂算法。它不是问“有几种不同的字符串”，而是问“有几个位置区间”。在 aaa 里，左边的 a 和右边的 a 虽然长得一样，但位置不同，所以都要分别计数。

我们要做的事情就是：把所有连续区间看一遍，只要这个区间是回文，就把答案加一。

2. 先用 s = "aaa" 手算一遍

长度 1a(0)、a(1)、a(2)3 个
长度 2aa(0..1)、aa(1..2)2 个
长度 3aaa(0..2)1 个

所以答案是 3 + 2 + 1 = 6。中心扩展法做的事，就是用更聪明的顺序把这 6 个区间找出来。

3. 跟着互动演示走

每个回文都有一个“中心”。奇数长度的中心是一个字符，比如 aba 中间的 b；偶数长度的中心在两个字符中间，比如 aa。

从中心往两边扩，只要左右字符相等，就找到一个新的回文子串，答案立刻加一。

4. 一句人话思路

把每个字符、每两个相邻字符中间都当成中心，向两边扩；每扩成功一次，就多找到一个回文子串。

这就是中心扩展。它本质上还是双指针：左指针往左走，右指针往右走。

5. 把思路翻译成 C++

LeetCode 提交时只需要下面这个 class Solution。辅助函数 expand 返回“从这个中心能扩出几个回文”。

class Solution {
    int expand(const std::string& s, int left, int right) {
        int found = 0;
        while (left >= 0 && right < static_cast<int>(s.size()) &&
               s[left] == s[right]) {
            ++found;   // s[left..right] 是一个新的回文子串
            --left;    // 继续往外看一层
            ++right;
        }
        return found;
    }

public:
    int countSubstrings(std::string s) {
        int ans = 0;
        for (int center = 0; center < static_cast<int>(s.size()); ++center) {
            ans += expand(s, center, center);     // 奇数长度
            ans += expand(s, center, center + 1); // 偶数长度
        }
        return ans;
    }
};

6. 现在轮到你

先别急着看答案。试着口算 s = "abba" 有多少个回文子串，再点开提示。

提示

先数四个单字符；再看偶数中心，bb 和 abba 都会出现。

答案与边界测试
展开：DP 对照，什么时候更适合用

如果你要反复查询某个区间 s[l..r] 是不是回文，可以建一张表：

dp[l][r] = (s[l] == s[r]) && (r - l <= 1 || dp[l + 1][r - 1])

它的时间也是 O(n^2)，但空间是 O(n^2)。LC647 只需要计数，所以中心扩展更轻；LC131、LC132 这类“切分”题，先用 DP 预处理回文表会更顺手。

复杂度与边界

字符串长度为 n。最多有 2n - 1 个中心，每个中心最坏扩 O(n)，所以时间 O(n^2)；只用几个变量，空间 O(1)。长度 1、全不相同、全相同、奇数回文、偶数回文都要测。
