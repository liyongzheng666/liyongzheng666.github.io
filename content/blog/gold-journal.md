最近上线了一个小站：[金日复盘](https://liyongzheng666.github.io/gold-journal/)。

它做的事情很简单：每天沿着「观察—依据—风险—失效」四步，记录我对黄金市场的判断，并单独记录工商银行如意金积存的产品报价，避免把国际参考行情和银行办理价格混为一谈。

几个原则：

- 不展示持仓、金额和收益，只公开判断过程
- 写「为什么」，也写「什么会证明自己错了」
- 不构成投资建议

站点用 React + Vite 构建，托管在 GitHub Pages 上，每日复盘直接在网页上填写、自动发布。

欢迎围观：<https://liyongzheng666.github.io/gold-journal/>
